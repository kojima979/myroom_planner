# MyRoom Planner (マイルーム・プランナー)

自分の部屋の寸法や形状、家具・建具のサイズを自由に入力・配置し、3次元空間上で任意の視点から観察・レイアウト検討・寸法測定ができるWebアプリケーションです。

検討したレイアウトは、施工・家具購入・搬入計画の記録用として、**クッキリと見やすい2D平面図（寸法入り）と配置家具のサイズ一覧表**を印刷・PDF出力することができます。

---

## 主な機能

### 1. 部屋の形状・寸法の自由作成
- **矩形および多角形・L字型の部屋に対応**:
  - 四角形の部屋（幅・奥行きを指定）はもちろん、頂点を追加・ドラッグ移動することでL字型や複雑な多角形の部屋を自由に作成できます。
- **壁一辺の長さを常時表示**:
  - 各壁セグメントの寸法（mm / cm）が壁に沿って常時表示されます。寸法ラベルをクリックして数値を直接入力変更することも可能です。
- **直角（90°）自動スナップ＆直角表示のON/OFF切り替え**:
  - 頂点をドラッグして移動する際、隣接する壁と90°（直角）や水平・垂直に近づくと自動的に吸着スナップします。緑色の直角記号（`∟ 90°`）の表示は、上部ツールバーまたは左サイドバーからON/OFFを切り替えられます。
- **天井高の調整と壁の自動透過**:
  - 天井の高さ（mm）を任意に設定可能。カメラの向きに応じて手前の壁が自動的に半透明になるため、部屋の内部を外側からストレスなく観察できます。

### 2. 家具・建具の配置とカスタマイズ
- **豊富なプリセットカタログ**:
  - **ベッド**: シングル・セミダブル・ダブル等、寸法変更自由なベッド
  - **机（デスク）**: 天板と脚で構成されるワークデスク
  - **椅子（チェア）**: 座面・背もたれ付きチェア（机の下に収納できるよう非干渉仕様）
  - **ソファー**: アームレスト付きのソファー
  - **本棚（シェルフ）**: 収納棚
  - **カーペット（ラグ）**: 床面に敷くラグ（非干渉仕様）
  - **冷蔵庫**: 2ドア〜ファミリータイプの冷蔵庫
  - **システムキッチン**: シンク・水栓・コンロ・作業台一体型キッチン設備
  - **テレビ（モニタ）**: スタンド付き薄型大画面テレビ・モニタ
  - **豆型ダイニングテーブル**: オーガニック曲線の豆型天板と丸テーパー脚のダイニングテーブル
  - **窓**: 壁面に配置する腰高窓などの建具
  - **扉（ドア）**: 開閉軌跡ガイド付きの室内ドア建具
  - **汎用形状（直方体・円柱）**: 任意の家電や収納、丸テーブルなどを表現可能
- **カーペット・椅子の重ね置き（非干渉）仕様と干渉警告の自動消去**:
  - 通常の家具同士や壁が重なった場合は衝突警告（赤色枠ハイライト＋ポップアップ）が表示されますが、**カーペットや椅子は他の家具と干渉せず、カーペットの上に家具を重ねたり、机の下に椅子をすっきり収めて配置**できます。
  - 干渉警告のポップアップ表示は視界の邪魔にならないよう**表示から2秒後に自動で消去**されます（左サイドバーの「部屋設定」から表示秒数を変更、または `0` 秒指定で非表示にすることも可能です）。
- **直感的な右クリックコンテキストメニュー**:
  - 3D空間上の家具を右クリックするだけで、「回転モードへ移行」「複製」「削除」を即座に実行できます。
- **任意の寸法・カラー変更**:
  - 配置したすべての家具は、幅 (W)・奥行き (D)・高さ (H) を1mm単位で自由に変更できます。カラーピッカーで色も変更可能です。
- **外部3Dモデルのインポート**:
  - お手持ちの `.glb`, `.gltf`, `.obj` 形式の3Dモデルファイルをドラッグ＆ドロップで読み込み、指定寸法に自動スケーリングして配置できます。

### 3. 壁との隙間（クリアランス）常時表示＆微調整
- 家具を選択すると、家具の前後左右（4側面）から対面する壁面までの最短距離（補助線＋寸法数値ラベル）がリアルタイムに常時表示されます。
- 右側のインスペクターパネルから「前壁まで 150mm」のように数値を直接入力することで、壁からの隙間をミリ単位で直感的に微調整できます。

### 4. 任意の場所の長さ測定（メジャー機能）
- 「2点間長さ測定」モードを有効にし、3D空間上の床・壁・家具の任意の2点をクリックして直線距離を測定できます。
- 直線距離だけでなく、各軸の差分（$\Delta X, \Delta Y, \Delta Z$）も詳細に表示されます。
- **端点スナップ機能**: 家具の角（頂点）や部屋の壁コーナーにマウスを近づけると自動で吸着スナップするため、正確な通路幅や家具間の隙間を簡単に測ることができます。

### 5. 2D平面図・寸法線および家具サイズ一覧の印刷・PDF出力
- 検討したレイアウトを紙面（A4サイズ）やPDFとしてきれいに残すことができます。
- **高コントラストな建築図面調印刷**:
  - 画面上のダークモードとは異なり、印刷時は**白背景＋くっきりとした黒線**でレンダリングされ、部屋の外枠、ドア開閉軌跡、家具の輪郭、壁の一辺の寸法、クリアランス寸法が明瞭に出力されます。
- **家具サイズ一覧表の自動出力**:
  - 平面図と連動した記号（F1, F2...）、家具の名称、種類、寸法（幅×奥行き×高さ mm / cm）、配置高さ（Y）をまとめた一覧表が自動で併記されます。

### 6. プロジェクトデータの保存・読み込み
- 作成した部屋の形状、壁寸法、配置家具、測定結果を含むプロジェクト全体を `.json` ファイルとしてワンクリックでエクスポート・インポートできます。

## 画面構成と基本操作

### 画面レイアウト
- **上部ツールバー**:
  - モード切り替え（家具配置・移動 / 部屋形状・壁寸法編集 / 2点間長さ測定）
  - 移動 / 回転ギズモの切り替え
  - 3D自由視点 / 2D平面図の切り替え
  - 壁の表示方式（自動透過 / 常時不透明 / 最小表示）
  - 保存（JSON書き出し）/ 読込（JSON読み込み）
- **左サイドバー**:
  - **家具追加**: プリセット家具のワンクリック追加、外部3Dモデルの読み込み
  - **部屋設定**: 矩形の部屋寸法指定、L字型の部屋プリセット適用、天井高・床色・直角スナップ設定
  - **配置一覧**: 配置済みオブジェクトの選択、複製、削除
- **中央3Dキャンバス**:
  - 3D空間ビューポート（家具ドラッグ移動、壁寸法表示、クリアランス表示、測定ライン描画）
- **右インスペクターパネル**:
  - 選択中家具の詳細編集（名称、色、幅・奥行き・高さ、壁からの距離微調整、配置座標、回転角）
  - 各壁一辺の寸法一覧編集
  - 測定履歴一覧

### マウス・カメラ操作
| 操作 | 3D自由視点 | 2D平面図 |
| :--- | :--- | :--- |
| **視点回転** | マウス左ドラッグ | （平行投影のため固定） |
| **平行移動（パン）** | マウス右ドラッグ / Shift + 左ドラッグ | マウス右ドラッグ / Shift + 左ドラッグ |
| **ズーム（拡大・縮小）** | マウスホイールスクロール | マウスホイールスクロール |
| **家具の選択** | 家具を左クリック | 家具を左クリック |
| **家具の右クリックメニュー** | 家具を右クリック（削除・複製・回転モード移行） | 家具を右クリック（削除・複製・回転モード移行） |
| **家具の移動・回転** | 3Dギズモ（矢印/リング）をドラッグ | 3Dギズモをドラッグ |
| **頂点の移動（部屋編集時）** | オレンジ色の頂点をドラッグ | オレンジ色の頂点をドラッグ |
| **測定キャンセル** | マウス右クリック | マウス右クリック |

### キーボードショートカット
| キー | 動作 |
| :--- | :--- |
| `1` / `2` / `3` | モード切り替え（`1`: 家具配置 / `2`: 部屋編集 / `3`: 測定） |
| `G` | 3Dギズモの切り替え（移動 ⇄ 回転） |
| `V` | 視点切り替え（3D自由視点 ⇄ 2D平面図） |
| `Delete` / `Backspace` | 選択中の家具を削除 |
| `Escape` | 選択解除 / 測定のキャンセル / 印刷プレビューを閉じる |
| `Ctrl+P` / `Cmd+P` | 図面印刷・PDF出力プレビューを開く |

## 開発・実行方法

### 必要な環境
- [Node.js](https://nodejs.org/) (v18 以上推奨)
- npm (v9 以上)

### インストールと起動手順

1. **リポジトリのクローン / ディレクトリへ移動**:
   ```bash
   cd myroom_planner
   ```

2. **依存パッケージのインストール**:
   ```bash
   npm install
   ```

3. **ローカル開発サーバーの起動**:
   ```bash
   npm run dev
   ```

4. **ブラウザでアクセス**:
   - **起動したPC自身からアクセスする場合**:
     ターミナルに表示される `Local` のURL（通常は `http://localhost:5173/`）をブラウザで開いてご利用ください。
   - **ローカルネットワーク（同一Wi-Fi / LAN）上の他のPC・タブレットからアクセスする場合**:
     ターミナルに表示される `Network` のURL（例: `http://192.168.x.x:5173/`）を、他のPCのブラウザに入力してアクセスしてください（`vite.config.ts` にて `host: true` が設定済みのため、そのまま接続可能です）。

### ビルドと動作確認
```bash
# TypeScriptの型チェックおよび本番ビルド
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```

### Raspberry Pi 4 等での稼働・LAN内サーバー配信手順
本アプリケーションはブラウザ側（WebGL）で3D描画を行うフロントエンド完結型のため、Raspberry Pi 4 を「ローカルネットワーク内のWebサーバー」として常時稼働させ、Mac・Windows・タブレット等からアクセスする運用にも最適です。

#### 方法A：Mac等でビルドした `dist` フォルダのみを転送して配信する（軽量・推奨）
Raspberry Pi 側に Node.js を入れる必要がなく、メモリ消費も最小限で動作します。

1. **Mac / PC 側で本番ビルドを作成**:
   ```bash
   npm run build
   ```
2. **生成された `dist` フォルダを Raspberry Pi 4 に転送**:
   ```bash
   scp -r ./dist pi@<RaspberryPiのIPアドレス>:~/myroom_planner_dist
   ```
3. **Raspberry Pi 4 側で標準の Python HTTP サーバーを起動**:
   ```bash
   cd ~/myroom_planner_dist
   python3 -m http.server 5173 --bind 0.0.0.0
   ```
   起動後、LAN内の任意のPCのブラウザから `http://<RaspberryPiのIPアドレス>:5173/` でアクセスできます（Nginx 等のWebサーバーで `dist` を公開することも可能です）。

#### 方法B：Raspberry Pi 4 上に Node.js を導入して直接動かす
1. **Raspberry Pi 4 に Node.js (v18以上) をインストール**:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```
2. **プロジェクト一式を配置して依存パッケージをインストール**:
   ```bash
   cd myroom_planner
   npm install
   ```
3. **サーバー起動**:
   ```bash
   # 開発サーバーとして起動（LAN公開設定済み）
   npm run dev

   # または本番ビルド＋プレビューサーバーとして起動（ポート4173）
   npm run build && npm run preview
   ```

## 使用技術スタック
- **Frontend Framework**: React 18 / TypeScript (`strict: true`)
- **Build Tool**: Vite
- **3D Graphics**: Three.js / React Three Fiber (`@react-three/fiber`) / Drei (`@react-three/drei`)
- **State Management**: Zustand
- **UI Components & Icons**: Tailwind CSS / Lucide React
- **Validation**: Zod
- **ID Generator**: UUID
